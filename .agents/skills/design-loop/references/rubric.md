# 🔁 Rubric Evaluasi 5 Kriteria & Prosedur Loop (Tara Althea)

## 1. Rubric Penilaian Visual (Skala 1–5)

### 1. Composition (Bobot: 20%)
- **Skor 1-2**: Elemen bertumpuk canggung, whitespace sempit, ritme vertikal kacau.
- **Skor 3**: Grid standar rapi tapi membosankan.
- **Skor 4-5**: Tata letak berirama anggun, whitespace lapang dan intentional, flow pandangan mata natural.

### 2. Typography (Bobot: 25%)
- **Skor 1-2**: Ukuran font acak, font default sistem, kontras judul vs isi tidak terasa.
- **Skor 3**: Terbaca namun terkesan hambar.
- **Skor 4-5**: Hierarki ukuran tajam, line-height lega, tracking pas, font pairing berkarakter kuat.

### 3. Color & Contrast (Bobot: 20%)
- **Skor 1-2**: Teks abu-abu di atas latar putih tidak terbaca (gagal WCAG AA < 4.5:1), warna bentrok.
- **Skor 3**: Kontras cukup aman tapi kombinasi warna terasa default.
- **Skor 4-5**: Kontras tajam dan nyaman, palet 60-30-10 disiplin, aksen CTA mencuri perhatian seketika.

### 4. Visual Identity (Bobot: 20%)
- **Skor 1-2**: Tampak seperti template gratisan atau hasil prompt AI tanpa modifikasi.
- **Skor 3**: Bersih tapi mirip ratusan website lain di internet.
- **Skor 4-5**: Lolos "Portfolio Test". Unik, berwibawa, mencerminkan identitas produk Bos.

### 5. Polish & Details (Bobot: 15%)
- **Skor 1-2**: Margin miring, tombol tidak rata garisnya, border-radius belang-belang.
- **Skor 3**: Tidak ada bug visual mayor.
- **Skor 4-5**: Presisi piksel ekstrem, sudut radius konsisten, hover micro-transitions mulus.

---

## 2. Kriteria Berhenti Loop
Loop iterasi perbaikan akan terus berjalan secara otomatis sampai:
> **Rata-rata skor >= 4.0 dan tidak ada kriteria di bawah nilai 4.**
